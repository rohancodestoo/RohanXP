## 🎨 Overview

**RohanXP** is a unique, fully interactive portfolio website designed to look and feel exactly like the classic Windows XP operating system. Built with Vanilla HTML, CSS, and JavaScript, it offers a fun and nostalgic way to explore my projects, skills, and professional experience.

## ✨ Features

- **🪟 Authentic Windows XP UI:** Pixel-perfect start menu, taskbar, desktop icons, and draggable windows.
- **🔊 Nostalgic Sounds:** Classic Windows startup and interaction sound effects.
- **📂 Interactive Desktop:** Open folders, view projects, read the resume, and launch links directly from the desktop.
- **🛠️ Tech Stack Showcase:** Dedicated sections displaying tools and languages I use.
- **📱 Responsive:** Works beautifully across different screen sizes while maintaining the retro vibe.

## 💻 Tech Stack

- **HTML5:** Semantic structure and content.
- **Vanilla CSS3:** Custom styling for the authentic Windows XP aesthetic (no external UI libraries).
- **Vanilla JavaScript:** Window management, drag-and-drop functionality, start menu logic, and dynamic clock.

## 🛠️ Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rohancodestoo/RohanXP.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd RohanXP
   ```
3. **Open `index.html`:**
   Simply double-click `index.html` to open it in your browser, or use an extension like Live Server in VS Code for hot-reloading.
